# EntregaJá

Protótipo mobile-first de um aplicativo de delivery de comida, desenvolvido para a disciplina de Engenharia de Software.

## Fluxo da demonstração

1. Escolher o restaurante recomendado ou pesquisar uma opção.
2. Abrir o cardápio digital.
3. Adicionar produtos ao carrinho.
4. Ir para o checkout.
5. Informar nome, endereço e forma de pagamento fictícia.
6. Confirmar o pedido e visualizar a tela de sucesso.

## Como executar

Abra o arquivo [index.html](./index.html) diretamente no navegador. Não é necessário servidor, banco de dados ou instalação de dependências.

## Observação

Este é um protótipo acadêmico. Nenhum pagamento real é processado e os dados não são enviados para um servidor.

## Roteiro rápido para apresentação

- Comece mostrando o destaque visual do restaurante recomendado.
- Explique que a interface foi pensada primeiro para celular.
- Apresente as três alternativas de design e explique a escolha da ideia 3.
- Selecione um restaurante e adicione dois produtos.
- Mostre o resumo do pedido no checkout.
- Finalize usando dados fictícios e apresente a confirmação.
